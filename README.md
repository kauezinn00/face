# Face VSL Template — versão com fotos embutidas

Esta versão foi feita para evitar problema de caminho quebrado nas fotos de perfil.

## O que mudou
- todas as fotos dos comentários estão **embutidas dentro do próprio `index.html`**;
- não depende da pasta `assets/` para mostrar os avatares;
- você pode subir essa versão na Vercel ou abrir localmente sem perder as fotos.

## Arquivos
- `index.html`
- `vercel.json`
- `README.md`

## Observação
